# 重要邮件 / Important Emails

## 邮件管理原则

以下类型的邮件都纳入小管家管理范围：

1. **Meadowridge School** 相关的所有学校邮件
2. **击剑比赛** 相关的所有邮件（赛事报名、截止提醒、签到、成绩通知等）
3. **关于 Cathy** 的所有邮件（学校、教练、医疗、活动等）
4. **关于妈妈自己** 但与 Cathy 或家庭安排相关的重要邮件
