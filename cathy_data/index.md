# Cathy 小管家数据库 / Cathy Housekeeper Database

这里是何云熙 (Cathy He) 的北美生活综合数据库，由「Cathy 小管家」读取并回答击剑、学校、体能、生活、材料等问题。

## 文件说明

| 文件 | 用途 | 维护人 |
|------|------|--------|
| `profile.md` | Cathy 个人信息、USA Fencing 会员、Region、剑种、家庭联系方式 | 妈妈 |
| `school.md` | 学校、课程表、作业、考试、假期、重要日期 | 妈妈 |
| `physical.md` | 体能数据（身高、体重、跑跳、力量、拉伸、恢复） | 妈妈/教练 |
| `history.md` | 训练日志、伤病、重要节点、教练反馈 | 妈妈/教练 |
| `emails.md` | 重要邮件摘要与待办 | 妈妈 |
| `events.md` | 重要事件、日程、截止日期 | 妈妈 |
| `materials.md` | 证件、装备、学校/比赛申请材料 | 妈妈 |
| `handbook.md` | USA Fencing 规则大纲（年龄、赛事级别、积分等） | AI 整理，妈妈校对 |
| `tournaments.md` | 目标赛事清单、注册状态 | 参考 `fencing_tournament_helper.html` |
| `results.md` | 比赛成绩、排名、积分变化 | 妈妈 |

## 总览入口

更完整的数据库说明见 `cathy_data/cathy_index.md`。

## 使用方式

1. 直接打开任意 `.md` 文件编辑。
2. 给 Cathy 小管家提问时，AI 会先读取这些文件，再基于事实回答。
3. 如果信息不全，AI 会指出需要补充哪个文件。
