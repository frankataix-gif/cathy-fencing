# Cathy 击剑数据库 / Cathy Fencing Database

这里是何云熙 (Cathy He) 的专属击剑数据库。妈妈（或爸爸）可以在这里持续补充信息，AI 会读取这些文件后回答击剑相关问题。

## 文件说明

| 文件 | 用途 | 谁维护 |
|------|------|--------|
| `profile.md` | Cathy 个人信息、USA Fencing 会员、Region、剑种 | 妈妈/爸爸 |
| `handbook.md` | USA Fencing 规则大纲（年龄、赛事级别、积分等） | AI 整理，妈妈校对 |
| `tournaments.md` | 目标赛事清单、注册状态 | 参考 `fencing_tournament_helper.html` |
| `results.md` | 比赛成绩、排名、积分变化 | 妈妈 |
| `physical.md` | 体能数据（身高、体重、跑跳、力量等） | 妈妈/教练 |
| `history.md` | 训练日志、伤病、重要节点、教练反馈 | 妈妈/教练 |

## 使用方式

1. 直接打开任意 `.md` 文件编辑。
2. 给 AI 提问时，AI 会先读取这些文件，再基于事实回答。
3. 如果信息不全，AI 会指出需要补充哪个文件。
