# Cathy 小管家 / Cathy Housekeeper

Cathy 小管家是何云熙（Cathy He）在北美生活的综合数据库，涵盖击剑、学校、体能、生活、材料等。

## 文件说明

| 文件 | 用途 | 维护人 |
|------|------|--------|
| `profile.md` | Cathy 个人信息、USA Fencing 会员、Region、剑种、家庭联系方式 | 妈妈 |
| `school.md` | 学校、课程表、作业、考试、假期、重要日期、老师/同学信息 | 妈妈 |
| `physical.md` | 体能数据：身高、体重、跑跳、力量、拉伸、恢复、体检 | 妈妈/教练 |
| `history.md` | 训练日志、伤病、重要节点、教练反馈、成长记录 | 妈妈/教练 |
| `emails.md` | 重要邮件摘要、待办、需要回复或跟进的事项 | 妈妈 |
| `events.md` | 重要事件、日程、截止日期、旅行、比赛、学校活动 | 妈妈 |
| `materials.md` | 证件（护照、签证、会员证）、装备、学校申请材料、保险、医疗卡 | 妈妈 |
| `handbook.md` | USA Fencing 规则大纲（年龄、赛事级别、积分等） | AI 整理，妈妈校对 |
| `tournaments.md` | 目标赛事清单、注册状态 | 参考 `fencing_tournament_helper.html` |
| `results.md` | 比赛成绩、排名、积分变化 | 妈妈 |

## 使用方式

1. 直接打开任意 `.md` 文件编辑。
2. 给 Cathy 小管家提问时，AI 会先读取这些文件，再基于事实回答。
3. 如果信息不全，AI 会指出需要补充哪个文件。
